# 保险内容增长分析平台

## 启动

```bash
npm install
npm run dev
```

默认访问地址： http://localhost:5173

## Excel / CSV 列名

第一行可使用以下列名或别名，系统会自动映射到标准字段：

`标题` / `笔记标题`、`正文` / `笔记正文` / `内容正文`、`发布时间` / `日期` / `发布日`、`点赞` / `点赞数`、`收藏` / `收藏数`、`评论` / `评论数`、`形式` / `内容形式` / `笔记形式`、`链接` / `笔记链接` / `原文链接`、`账号` / `账号名称`、`粉丝` / `粉丝数`

核心字段必须存在：`账号名称`、`笔记标题`、`发布时间`、`点赞数`、`收藏数`、`评论数`（可使用对应别名）。`正文`、`内容形式`、`笔记链接`、`粉丝数` 缺失时会显示为 `—`。其他字段会保留在本地数据中，但不会在当前表格展示。

文件会在浏览器本地解析，不会上传到服务器。
